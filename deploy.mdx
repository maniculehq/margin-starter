Margin builds the site from this repository's default branch. Each build reads `docs.json` and every page, then replaces the live site in one step, so readers never see a half-built site.

## Hosted on Manicule

Paste this repository's URL into Manicule to get a live site without connecting GitHub. Keep the repository public: Manicule reads public repositories only.

- New commits appear on the live site within an hour.
- Search engines don't index the site until you connect GitHub or add a custom domain.

Connect GitHub when you want each push to deploy right away, or when your docs live in a private repository.

## Run it yourself

Margin is open source under Apache 2.0. To host the site on your own infrastructure, follow [Self-host Margin](https://margin.manicule.dev/docs/deploy/self-host).
