## How the site is built

Your repository holds everything:

- `docs.json` sets the site's name, colors and sidebar.
- Each `.mdx` file is one page, written in Markdown with a few components.

Margin reads Mintlify's `docs.json` format. If you have a Mintlify site already, see [Migrate from Mintlify](https://margin.manicule.dev/docs/migrate-from-mintlify).
