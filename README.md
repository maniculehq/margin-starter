# Margin starter

A documentation site you can copy and make your own. It uses the `docs.json` format that [Margin](https://github.com/maniculehq/margin) and Mintlify both read.

## Use it

1. Click **Use this template** above and create a **public** repository.
2. Paste the new repository's URL into the docs step on [Manicule](https://app.manicule.com) to get a live site, or follow Margin's README to run it yourself.
3. Edit `docs.json` and the `.mdx` pages, then push. Start with `quickstart.mdx`.

## What's inside

- `docs.json`: the site's name, colors and sidebar.
- `index.mdx`, `quickstart.mdx`: the first pages a reader sees.
- `writing/`: how to add pages and use components.
- `deploy.mdx`: how changes reach the live site.
